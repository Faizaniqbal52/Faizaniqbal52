### 🚀 Research Programs

<img src="https://user-images.githubusercontent.com/74038190/212284100-561aa473-3905-4a80-b561-0d28506553ee.gif" width="100%">

**1 · Language AI**

| Repo | Description | Stack |
|---|---|---|

| Repo | Description | Stack |
|---|---|---|
| [**KoshurOCR**](https://github.com/Faizaniqbal52/KoshurOCR) | 5-generation OCR research program (CNN → CRNN+CTC → PARSeq → TrOCR → Arabic-TrOCR) · 11 architectural iterations · 673K-sample ecosystem | PyTorch · ViT · TrOCR · OpenCV |
| [**Koshur-Pixel**](https://github.com/Faizaniqbal52/Koshur-Pixel) | First large-scale synthetic OCR dataset for Kashmiri Nastaliq · 613,078 image-text pairs · arXiv-published | SynthOCR-Gen · Python |

| Repo | Description | Stack |
|---|---|---|
| [**PhysicalHazardBenchmark**](https://github.com/Faizaniqbal52/PhysicalHazardBenchmark) | 68-scenario benchmark evaluating 5 frontier LLMs on physical hazard reasoning across multi-sensor contexts · under review | Python · cs.AI |
